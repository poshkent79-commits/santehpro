Что заполнять дальше в RuStore:

1. Скриншоты для планшетов: можно оставить пустым (в RuStore написано «необязательно»).

2. Ссылка на видео: можно оставить пустым (необязательно).

3. Нажмите внизу кнопку «Сохранить» / «Далее».

4. Следующий шаг — «О приложении» / «Версия приложения»:

  • Категория: Услуги / Инструменты / Дом и быт
  • Возрастной рейтинг: 3+ или 12+
  • Политика конфиденциальности: https://santehpro.info/privacy
  • Загрузка APK / AAB сборки: если требуется файл сборки, мы подготовим актуальный APK для RuStore.
